## Singularity安装COMSOL

collapsed:: true
	- ((66330953-30ba-4733-b613-5ba891d66493)), ((69202eab-d4f0-48e6-8c09-9ddb00b57ab6))
- 需求：在Singularity中安装COMSOL，此处版本为6.4
- 由于是Windows系统，使用 VMware 创建 CentOS 虚拟机，启动之前“虚拟机设置”中挂载ISO映像，右下角右键图标连接 [Linux 虚拟机内挂载 iso 文件 - 梦缘&江南~ - 博客园](https://www.cnblogs.com/koreyoshi/articles/8884530.html)
  logseq.order-list-type:: number
- 在CentOS中安装Singularity，创建Ubuntu 22.04沙箱
  logseq.order-list-type:: number
- 挂载COMSOL安装映像（例如`--bind /home/centos/media/COMSOL:/COMSOL`）到沙箱中，安装COMSOL
  logseq.order-list-type:: number
- 安装依赖：`apt install libxrender1 libxtst6 libxi6 libgtk-3-0 packagekit-gtk3-module libcanberra-gtk-module libcanberra-gtk3-module fonts-wqy-zenhei fonts-wqy-microhei dbus-x11`
  logseq.order-list-type:: number
- 默认安装位置：`/usr/local/comsol64/Multiphysics`（版本号根据实际修改），执行`/usr/local/comsol64/Multiphysics/bin/comsol`以启动
  logseq.order-list-type:: number
- 设置环境变量：执行`touch /etc/comsol_bashrc`在安全位置创建环境变量文件，然后写入以下内容
  logseq.order-list-type:: number
  
  ``` bash
  # COMSOL
  export COMSOL_HOME=/usr/local/comsol64
  export PATH=$COMSOL_HOME/multiphysics/bin:$PATH
  export COMSOL_LICENSE_FILE=$COMSOL_HOME/multiphysics/license/license.dat
  export COMSOL_PREFSDIR=$HOME/.comsol/prefs
  export COMSOL_TMPDIR=$HOME/comsoltmp
  export COMSOL_CONFIGURATION=$HOME/.comsol/config
  ```
- 提示“using the fallback c locale”：执行以下命令
  logseq.order-list-type:: number
  
  ``` bash
  sudo apt update
  sudo apt install -y locales
  sudo locale-gen en_US.UTF-8
  sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
  ```
- 提示“dconf-CRITICAL **: 05:49:32.344: unable to create file '/run/user/1000/dconf/user': Read-only file system.  dconf will not work properly.”：执行以下命令，在安全位置创建启动脚本
  logseq.order-list-type:: number
  
  ``` bash
  cat > /etc/comsol_run <<'EOF'
  #!/bin/bash
  export XDG_RUNTIME_DIR=/tmp/xdg-runtime-$USER
  mkdir -p "$XDG_RUNTIME_DIR"
  chmod 700 "$XDG_RUNTIME_DIR"
  mkdir -p "$XDG_RUNTIME_DIR/dconf"
  exec comsol "$@"
  EOF
  chmod +x /etc/comsol_run
  ```
