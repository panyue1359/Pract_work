## scholaraio——LLM辅助文献工作台
collapsed:: true
	- ((69b41a65-81ef-4c16-ae07-7e37ac741551))
- 基于python编写的一套文献管理和解析工具，并基于这些工具建立了若干套工作流程（文献检索、回顾、写作、演说），接入智能体后可以自动执行这些流程
- 流程：创建新文件夹->创建uv虚拟环境（`uv venv`）->下载完整依赖（`uv pip install "scholaraio[full]"`）->配置环境变量（`scholaraio setup`）->手动修改"config.local.yaml"文件->接入智能体->跨项目调用
- 总体使用流程：导入文献、创建工作区、获取PDF、解析PDF创建md笔记、领域分析，可用工具列表使用`uv run scholaraio -h`查看
- 手动导入文献（以Zotero为例）：
  
  ``` bash
  # 查看zotero集合列表，获取集合代码
  uv run scholaraio import-zotero --local <zotero.sqlite路径> --list-collections
  # 导入指定集合并创建工作区(工作空间名称为集合名称)
  uv run scholaraio import-zotero --local <zotero.sqlite路径> --collection <集合KEY> --import-collections
  # 导入时可指定文献类型
  --item-type journalArticle conferencePaper thesis report preprint
  # 查看可用的zotero导入操作
  uv run scholaraio import-zotero -h
  # 查看可用的工作空间操作
  uv run scholaraio ws -h
  # 查看所有文献列表（只读）
  uv run scholaraio gui
  ```
- 因为scholaraio后续的工作流程都依赖PDF全文，所以最方便的做法是收集所有文献的PDF，让Agent自己使用这些PDF创建文献条目。但要注意手动检查，文献多的时候Agent可能有遗漏。手动查看文献信息的三种方法：
	- 执行`uv run scholaraio ws show 工作空间名称`查看工作空间中的文献路径
	- `uv run scholaraio gui`打开可交互的文献列表，查看文献标题、作者、目录、doi信息、有无PDF
	- 复制一个文献路径（或者doi），执行`uv run scholaraio show 文献路径`可查看该文献详细信息。相比`gui`命令可以看到更多信息，包括文献id（paper_id）、被引用数和引用数、Semantic Scholar网址等等，paper_id也可以用来定位文献
