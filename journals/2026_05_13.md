## ParaView state file
collapsed:: true
	- ((63ecba55-d584-42b4-86ec-916e1116ee13))
- ParaView支持将filter pipeline导出为state file以便复用，state file有两种格式：.pvsm和.py，后者更易于理解和编辑。[Can anyone show me how to use one state file multiple times? - ParaView Support - ParaView](https://discourse.paraview.org/t/can-anyone-show-me-how-to-use-one-state-file-multiple-times/5861/3)
- 将state file拖放到ParaView图标上可直接加载，命令行指令为`paraview.exe --state="state file path"`
