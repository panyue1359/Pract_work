## Anki自定义安装位置
collapsed:: true
	- ((6909f086-221a-4495-84a3-88c83945dfb7))
- 需求：在Windows系统中安装Anki时只能自定义启动器位置（Anki官网提供的下载链接是启动器的，不是主程序的），主程序默认安装在C盘，会占用大量空间，需要移动到其他磁盘
- 根据官方说明，主程序安装目录为`%LOCALAPPDATA%\AnkiProgramFiles`，将其移动到其他位置，然后使用uv（python包管理器）启动即可。但是官方给出的批处理脚本存在问题，以下是AI给出的代码。将以下代码保存在txt中，然后把后缀改成vbs，双击启动（注意替换主程序目录，第一次使用前先在主程序目录执行`uv sync`） [Managing Files - Anki Manual](https://docs.ankiweb.net/files.html#running-from-a-flash-drive)
  
  ``` bash
  Set WshShell = CreateObject("WScript.Shell")
  WshShell.Run "cmd /c cd /d d:\Programs\AnkiProgramFiles && uv run anki", 0, False
  ```
- 更新：更新启动器后在主程序目录执行`uv sync`，然后使用上面的vbs脚本启动
