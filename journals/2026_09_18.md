- 需求：加载本地大模型guff文件，创建兼容OpenAI格式服务端，供大模型客户端调用
- 当前主流的引擎是Ollama和llama.cpp，KoboldCpp是基于llama.cpp开发的单文件CLI工具有简单的图形界面，LM Studio是基于llama.cpp的客户端图形界面漂亮，下载模型方便。Ollama占用内存大，效率低，推荐llama.cpp框架。 [本地端侧AI引擎插件指引 | MewCo-AI Studio](https://mewco-ai.github.io/2024/03/13/engine/)
- LM Studio引擎使用：开发者界面中选择模型启动，获得服务地址，支持OpenAI和Anthropic格式，还可添加API Key。模型可以从Model Search界面下载。[【开源AI助手】对接本地LM Studio教程 图形化运行LLM和VLM神器(2026版)_哔哩哔哩_bilibili](https://www.bilibili.com/video/BV18boVBFEpd/)
	- Linux系统可以通过Docker使用，拉取lm-studio镜像，启动守护进程指令如下。其中PUID和PGID是Linuxserver特别提供的用户权限设置接口，以便统一容器和宿主机的用户权限，具体参数看实际情况 [linuxserver/lm-studio - Docker Image](https://hub.docker.com/r/linuxserver/lm-studio)
	  ``` bash
	  docker run -d --name=lm-studio \
	    --network=host \
	    --privileged \
	    -e PUID=1052 \
	    -e PGID=1053 \
	    -e TZ=Etc/UTC \
	    -e LC_ALL=zh_CN.UTF-8 \
	    -p 3001:3001 \
	    -v $HOME/lmstudio/:/config/ \
	    linuxserver/lm-studio
	  ```
	- 服务端口可选择被局域网其他设备发现，在其他设备上请求模型会直接在lm-studio中加载相应模型，不需要提前手动加载
- LocalAI默认从Hugging Face下载模型，在Windows系统上需要Docker。[LocalAI · Make AI run on every machine](https://localai.io/)
	- 手动添加URL不是模型路径，而是yaml路径。添加模型仓库的URL也是index.yaml。
