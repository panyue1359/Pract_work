## 本地大模型聊天客户端

collapsed:: true
	- ((69b41a65-81ef-4c16-ae07-7e37ac741551))
- 需求：大模型聊天客户端，调用本地大模型，允许从国内源下载模型，或者手动放置模型。主要测试端侧小模型，如MiniCPM5、Gemma4、Qwen2.5、Spark。
- 测试系统：Intel(R) Core(TM) i7-10700 CPU @ 2.90GHz，两根[8G] Kingston 99P5702-014.A00G
- 检索词：llama desktop，llama 桌面，gguf mcp
- LM Studio：聊天桌面客户端，自带模型广场，支持模型很多，工具调用需要自己编写 [LM Studio Bionic - Agent for Work and Code](https://lmstudio.ai/)
- Chaty：有聊天和代码两种模式，内存占用低，聊天模式支持的模型较多，代码模式部分模型不可用 [Fangyuan025/Chaty: Private, on-device AI desktop app — GGUF (llama.cpp) & MLX, running Muse-Glimmer and Qwen3.8 with their native reasoning-effort ladders wired in as real controls.](https://github.com/Fangyuan025/Chaty)
- MiniCPM 本地智能体（自包含便携版）：release包损坏，仓库只含前端代码 [yuxiukundagege-wq/minicpm-portable: MiniCPM5-2B 本地智能体 · 自包含离线便携版（Ollama+模型+桌面UI一键启动）](https://github.com/yuxiukundagege-wq/minicpm-portable)
- Llama Console Portable 🦙：由llama驱动的Agent客户端，需要手动下载.gguf文件到model，运行run-server.bat时失败 [autostoppeur48/llama-console-portable: Your private AI workbench in one folder — chat with a local LLM or let the coding agent read, write and run code on your machine. 100% offline, no cloud, no account.](https://github.com/autostoppeur48/llama-console-portable)
- Ollama Portable：由Ollama便携版驱动的聊天软件，自动下载Gemma4-E2B模型，内存直接爆满 [ekhos-ai/ollama-portable: a portable web chat interface for runnning local LLMs](https://github.com/ekhos-ai/ollama-portable)
