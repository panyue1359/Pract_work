- zellij从0.43.0版本开始支持共享终端，在会话中依此执行`Ctrl+O`->`S`，打开共享界面，根据提示按Enter和Space键开启共享
- 如果是从老版本升级上来的，共享功能没有开启，需要手动添加。打开`.config\zellij\config.kdl`，在`keybinds>session`下添加如下代码
  
  ``` bash
          bind "s" {
              LaunchOrFocusPlugin "zellij:share" {
                  floating true
                  move_to_focused_tab true
              };
              SwitchToMode "Normal"
          }
  ```
