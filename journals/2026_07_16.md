- codeg是一款开源免费的跨平台智能体客户端，想要在WSL2中使用codeg调用Vibeflow Studio提供的技能，以兼顾美观和效率
- 安装codeg：下载deb安装包，执行`sudo dpkg -i codeg安装包`安装，如果缺东西则执行`sudo apt-get install -f`
- 设置中文界面：参考 [Windows 安装与快速使用](https://www.yuque.com/bluedreams/vibeflow/xk06uk4tx4zme0l2#qnoOl) 2.6部分，执行以下命令设置中文环境
  ``` bash
  sudo apt update
  sudo apt install -y fonts-noto-cjk fonts-noto-cjk-extra fonts-wqy-microhei fonts-wqy-zenhei fontconfig locales
  fc-cache -fv
  sudo locale-gen zh_CN.UTF-8
  sudo update-locale LANG=zh_CN.UTF-8
  ```
- 运行codeg：执行`codeg`命令打开界面。如果WSL2设置了镜像网络，可以在codeg中开启网页服务端，在宿主机浏览器打开即可。
- 如果要直接使用这个界面，WSL2无法直接获取宿主机系统中的输入法打出的中文，需要在WSL2中另外安装输入法。这里我使用rime+wanxiang方案
	- 执行`sudo apt install fcitx5-rime fcitx5 librime-plugin-lua librime1 librime-bin librime-plugin-octagram`安装小企鹅和wanxiang依赖 [Fcitx5-Linux （小企鹅） - 万象拼音](https://amzxyz.github.io/rime-wanxiang/doc/fcitx5-linux/)

	- 执行`mkdir -p ~/.local/share/fcitx5/rime`创建小企鹅配置文件夹
	  logseq.order-list-type:: number
	- 下载万象辅助工具deb安装包 [Releases · amzxyz/RIME-LMDG](https://github.com/amzxyz/RIME-LMDG/releases)，执行`sudo dpkg -i 万象辅助工具安装包`安装
	  logseq.order-list-type:: number
	- 执行`wanxiang-tool`启动万象辅助工具，全量安装
	  logseq.order-list-type:: number
	- 安装完重启WSL2，然后执行`pkill fcitx5`和`fcitx5 --disable=wayland -d`启动小企鹅服务 [关于fcitx5在WSL下使用的问题 · fcitx/fcitx5 · Discussion #532](https://github.com/fcitx/fcitx5/discussions/532)
	  logseq.order-list-type:: number
	- 关闭WSL2窗口再开一个新的，执行`fcitx5-confitool`打开小企鹅配置界面，将“中州韵”上移到第一位，点确定
	  logseq.order-list-type:: number
	- 打开codeg界面，即可使用万象拼音
