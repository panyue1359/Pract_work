- ## EPUB排版
  collapsed:: true
	- ((6631b95e-cfe8-4b44-928f-90bfa970add1))
- EPUB电子书使用CSS样式控制排版
- 一些中文排版样式：[sigil-template/dk-template.css at master · Eninix/sigil-template](https://github.com/Eninix/sigil-template/blob/master/dk-template.css)，[feynmantextbook/OEBPS/flow0006.css](https://github.com/suisuyy/feynmantextbook/blob/b53869b8e1b3fc47fc49a792db32c9b0a415ad18/OEBPS/flow0006.css#L48)
- 对特殊页面套用对应样式，对BOOKpandoc自带样式做一些修改
  ``` css
  body> :not(.title-page):not(.dedication):not(#TOC):not(.toc):not(#title-block-header) {
      padding-left: 2cm;
      padding-right: 2cm;
      padding-bottom: 2cm;
  }
  .divider {
      page-break-before: always;
      break-before: page;
      text-align: center;
      margin: 3em 0;
      color: var(--mid-gray);
      font-size: 0.75rem;
      letter-spacing: 1em;
      page-break-inside: avoid;
  }
  a {
      color: #0066cc;
      text-decoration: none;
  }
  ```
- 对版权页我使用blockquote样式，目录使用TOC样式，前言使用dedication样式，后记标题使用epilogue，注释区域前使用divider样式分割
