## fatel: detected dubious ownership
collapsed:: true
	- ((65b7175a-ac60-495e-b89a-feba0f69db61))
- 报错详情：`fatal: detected dubious ownership in repository`，意思是Git 检测到仓库目录的所有者与当前运行 Git 的用户不匹配
- 更改本地仓库所有者：右键点击该仓库文件夹-> **属性->安全->高级**，将所有者更改为当前的 Windows 登录用户，并勾选“替换子容器和对象的所有者”。[git fatal detected dubious ownership in repository 的解决方法 - lindexi - 博客园](https://www.cnblogs.com/lindexi/p/17679816.html)
