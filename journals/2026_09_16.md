- 需求：智能体客户端，调用本地大模型，支持工具调用，允许从国内源下载模型，或者加载本地模型。主要测试端侧小模型，如MiniCPM5、Gemma4、Qwen2.5、Spark。
- 测试系统：Intel(R) Core(TM) i7-10700 CPU @ 2.90GHz，两根[8G] Kingston 99P5702-014.A00G
- 检索词：gguf agent tool calling
- Chaty：代码模式即智能体模式，可操作文本文件和执行PowerShell命令，内存占用低 [Fangyuan025/Chaty: Private, on-device AI desktop app — GGUF (llama.cpp) & MLX, running Muse-Glimmer and Qwen3.8 with their native reasoning-effort ladders wired in as real controls.](https://github.com/Fangyuan025/Chaty)
- LM Studio Bionic：桌面客户端，自带模型广场，支持的模型很多，内存占用大 [LM Studio Bionic - Agent for Work and Code](https://lmstudio.ai/)
- Mistral：跨平台CLI工具，可加载本地模型，支持聊天和Agent两种模式，Agent模式MiniCPM和Spark模型均不可用。内存占用略大。 [EricLBuehler/mistral.rs: Fast, flexible LLM inference](https://github.com/EricLBuehler/mistral.rs)
- unsloth：自动在C盘安装依赖，空间不足无法测试 [unslothai/unsloth: Local UI to run and train LLMs and diffusion models. Supports GGUF, MLX, Qwen3.8, DeepSeek-V4, MiniMax-H3, Gemma 4, FLUX and more.](https://github.com/unslothai/unsloth)
